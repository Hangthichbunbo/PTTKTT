# 📘 PTTKTT – Phân tích & Thiết kế Thuật toán

## 📖 Giới thiệu
Repository này được tạo nhằm **tổng hợp và ôn tập kiến thức cho môn học Phân tích và Thiết kế Thuật toán (PTTKTT)**, thuộc ngành Công nghệ Thông tin, Trường Đại học Giao thông Vận tải (UTC).  
Nội dung bao gồm:
- Đề cương môn học (`De cuong PTTKTT.docx`)  
- Các ví dụ, bài tập thực hành về **thuật toán sắp xếp** và kiểm thử (`sapxep`, `test`)  
- Tài liệu hỗ trợ sinh viên trong quá trình học và ôn thi.

---

## 📂 Cấu trúc thư mục
- **sapxep/**: Chứa các chương trình C++ minh họa các thuật toán sắp xếp (Selection Sort, Bubble Sort, Merge Sort, …).  
- **test/**: Các file kiểm thử, ví dụ chạy chương trình để minh họa kết quả.
- **Bai_tap.pdf**: Bài tập các chương (chỉ chứa đề bài).  
- **De cuong PTTKTT.docx**: Đề cương chi tiết môn học, bao gồm nội dung lý thuyết, ý tưởng triển khai và yêu cầu thực hành.  

---

## 🛠️ Công nghệ sử dụng
- **Ngôn ngữ lập trình:** C++ (100%)  
- **Môi trường:** Có thể chạy trên bất kỳ IDE nào hỗ trợ C++ (Code::Blocks, Visual Studio, Dev-C++, …).  

---

## 🚀 Cách sử dụng
1. Clone repository về máy:
   ```bash
   git clone https://github.com/Hangthichbunbo/PTTKTT.git
2. Mở thư mục `sapxep/` để xem và chạy các thuật toán mẫu.
3. Tham khảo `test/` để kiểm thử và đối chiếu kết quả.

4. Đọc file De cuong PTTKTT.docx để nắm rõ nội dung môn học và chuẩn bị cho kỳ thi.
